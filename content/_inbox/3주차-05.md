## 슬라이드 U — 숫자의 종류

숫자를 만들기 위해서는 단순히 숫자 입력하면 됨
```python
>>> print(273)
273
>>> print(52.273)
52.273
```

`type()` 함수로 소수점 없는 숫자와 있는 숫자를 출력
```python
>>> print(type(52))
<class 'int'>
>>> print(type(52.273))
<class 'float'>
```

- **Int** : 정수
- **Float** : 부동 소수점 (실수)
  - 일반적으로 프로그래밍 언어에서는 두 자료형을 구분해서 사용

## 슬라이드 V — 숫자 연산자 · 사칙 연산자

| 연산자 | 설명 | 구문 | 연산자 | 설명 | 구문 |
|---|---|---|---|---|---|
| `+` | 덧셈 연산자 | 숫자 + 숫자 | `*` | 곱셈 연산자 | 숫자 * 숫자 |
| `-` | 뺄셈 연산자 | 숫자 - 숫자 | `/` | 나눗셈 연산자 | 숫자 / 숫자 |

```python
>>> print("5 + 7 =", 5 + 7)
5 + 7 = 12
>>> print("5 - 7 =", 5 - 7)
5 - 7 = -2
>>> print("5 * 7 =", 5 * 7)
5 * 7 = 35
>>> print("5 / 7 =", 5 / 7)
5 / 7 = 0.7142857142857143
```

> 확인함: `5 / 7` 은 두 엔진 모두 `0.7142857142857143` 로 같다. 그대로 써도 된다.

## 슬라이드 W — TypeError 예외

서로 다른 자료를 연산할 경우
```python
>>> string = "문자열"
>>> number = 273
>>> string + number
```

오류
```
Traceback (most recent call last):
  File "<pyshell#3>", line 1, in <module>
    string+number
TypeError: can only concatenate str (not "int") to str
```
손글씨: "TypeError 예외가 발생했어요."

> **주의**: 오류 메시지 문구가 엔진마다 다르다.
> - CPython: `can only concatenate str (not "int") to str`
> - 브라우저 엔진: `cannot concatenate 'str' and 'int' objects`
>
> 채점은 오류 **종류**(TypeError)로만 하고 있으니 문제없지만,
> 설명에 메시지를 그대로 적을 때는 "환경에 따라 문구가 다를 수 있다" 고 덧붙일 것.

## 슬라이드 X — 키워드로 정리하는 핵심 포인트

- **숫자 자료형** : 소수점이 없는 정수형과 소수점이 있는 실수형 (부동 소수점)이 있다.
- **숫자 연산자** : 사칙연산자와 `//` (정수 나누기 연산자), `%` (나누기 연산자),
  `**` (제곱 연산자) 등이 있다.
- **연산자** : 우선순위가 존재하는데, 곱하기와 나누기가 가장 우선이고
  더하기와 빼기가 다음으로, 잘 모를 때는 괄호를 입력해 나타낸다.

## 슬라이드 Y — 실습 화면 (Thonny) · 삼각형 넓이에서 만난 오류

파일 `ss.py`. 편집기에 보이는 코드 (탭에 `*` 가 있어 저장 전 상태)
```python
bottom = int(input("밑변의 길이를 입력해 주세요"))
height = input("높이를 입력해 주세요")

s = bottom * height / 2
print("넓이는 = ", s)
```

Shell 에 남은 실행 결과
```
>>> %Run ss.py
 밑변의 길이를 입력해 주세요100
 높이를 입력해 주세요200
 Traceback (most recent call last):
   File "C:\Users\James\Desktop\ss.py", line 4, in <module>
     s = bottom * height / 2
TypeError: can't multiply sequence by non-int of type 'str'
```

> **해석**: 오류 메시지가 `can't multiply sequence by non-int of type 'str'` 이라는 것은
> 곱셈의 **양쪽이 모두 문자열**이었다는 뜻이다. 즉 실행 당시에는 1행에도 `int()` 가
> 없었고(`bottom = input(...)`), 오류를 보고 나서 `int()` 를 추가하신 상태의 화면이다.
> 탭에 `*` (저장 안 됨)가 있는 것도 이와 맞는다.
>
> 실행 당시 코드
> ```python
> bottom = input("밑변의 길이를 입력해 주세요")   # "100"
> height = input("높이를 입력해 주세요")          # "200"
> s = bottom * height / 2                        # "100" * "200" -> TypeError
> ```
>
> 두 엔진에서 같은 메시지가 나오는 것을 확인했다.
> 참고로 `height` 만 문자열이었다면(`100 * "200"`) 문자열 반복이 되어 통과하고,
> 그 다음 `/ 2` 에서 `unsupported operand type(s) for /: 'str' and 'int'` 가 난다.
> 두 경우를 비교하면 아주 좋은 문제가 된다.

## 적용 시 만들 예제 후보 (배치 5)

- `int()` 를 한쪽에만 씌웠을 때 나는 오류 두 가지 비교
  (`"100" * "200"` vs `100 * "200"` 후 `/ 2`)
- 삼각형 넓이 계산기를 올바르게 완성하기 (양쪽 다 `int()`)
- `5 / 7` 처럼 나누어떨어지지 않는 나눗셈의 결과 예측
- 사칙연산 결과 예측 (교재의 5, 7 예제 그대로)
