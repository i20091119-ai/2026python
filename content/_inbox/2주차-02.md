## 슬라이드 J — 3.4.4 input 의 두 가지 사용법

사용자 입력이 **있는** 경우
```python
question = input("조언을 구하고 싶으면 질문을 입력하고 엔터 키를 누르세요.\n")
```

사용자 입력이 **없는** 경우 (그냥 멈춰 세우는 용도)
```python
input("\n\n마치려면 엔터 키를 누르세요.")
```

> 두 번째는 리턴값을 변수에 담지 않는다. 값을 받으려는 게 아니라
> 엔터를 누를 때까지 프로그램을 멈춰 두려는 것이 목적.
