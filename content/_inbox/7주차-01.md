## 화면 D — df.py · 함수가 왜 필요한지 보여주는 실습

```python
for i in range(1, 71) :
    print("*", end="")
print("\n안녕하세요.  홍길동입니다.")
for i in range(1, 71) :
    print("*", end="")
print("\n오늘도 열심히 파이썬을 배웁니다.")
for i in range(1, 71) :
    print("*", end="")
print("\n안녕히 계세요")
for i in range(1, 71) :
    print("*", end="")
```

Variables: `i = 70`

Shell
```
**********************************************************************
안녕하세요.  홍길동입니다.
**********************************************************************
오늘도 열심히 파이썬을 배웁니다.
**********************************************************************
안녕히 계세요
**********************************************************************
```

빨간 펜: 맨 위 `for` 반복문 두 줄을 크게 동그라미 → **이 덩어리가 네 번 반복된다**

> **이 화면의 의도**: 똑같은 두 줄이 네 번 반복되는 것을 보여준 뒤,
> "이걸 함수로 묶으면 되겠다" 로 넘어가는 도입부다.
> 앱에서도 이 흐름 그대로 문제를 만들면 좋다.
> (반복 코드 → 함수로 묶기 → 매개변수로 개수 조절)
>
> **새로 나온 문법**: `print("*", end="")`
> `end` 는 출력 끝에 붙일 문자열이다. 기본값이 `"\n"` 이라 보통 줄이 바뀌는데,
> `end=""` 로 두면 줄바꿈 없이 이어 붙는다. 그래서 별이 한 줄로 70개 나온다.
> `range(1, 71)` 이므로 70번 반복인 것도 짚어 줄 것.
>
> 확인함: `end=""`, `sep="-"` 모두 두 엔진에서 동일하게 동작한다.

## 슬라이드 E — 함수에 매개변수 만들기

```
def 함수 이름(매개변수, 매개변수, ...):
    문장
```

Thonny 자동완성 팝업으로 `print` 자체의 정의를 보여주심
```
def print(value, ..., sep=' ', end='\n', file=sys.stdout, flush=False)

Prints the values to a stream, or to sys.stdout by default.
Optional keyword arguments:
  file:  a file-like object (stream); defaults to the current sys.stdout.
  sep:   string inserted between values, default a space.
  end:   string appended after the last value, default a newline.
```

> **아주 좋은 연결**: 지금까지 써 온 `print` 도 매개변수를 가진 함수였다는 것을
> 실제 정의를 띄워서 보여주신다.
> - `sep` : 값들 **사이**에 넣을 문자열 (기본값 공백 한 칸)
> - `end` : 마지막 값 **뒤**에 붙일 문자열 (기본값 줄바꿈)
>
> 1주차에서 "쉼표로 구분하면 공백이 자동으로 들어간다" 고 배운 것이
> 사실 `sep=' '` 때문이었다는 걸 여기서 알게 된다. 꼭 연결해 줄 것.
>
> 확인 결과 (두 엔진 동일)
> | 코드 | 출력 |
> |---|---|
> | `print("a", "b", "c")` | `a b c` |
> | `print("a", "b", sep="-")` | `a-b` |
> | `print("x", end="|")` 다음 `print("y")` | `x|y` |

## 적용 시 만들 예제 후보 (7주차 배치 1)

- `print(end="")` 로 한 줄에 별 찍기

- 1주차의 "쉼표는 공백이 들어간다" 를 `sep` 로 다시 설명하기
- 반복되는 코드 네 덩어리를 함수 하나로 줄이기 (교수님 실습 그대로)
- 별 개수를 매개변수로 받는 `star_line(n)` 만들기
- `len()` 을 예로 매개변수와 리턴값 구분하기 (객관식)
