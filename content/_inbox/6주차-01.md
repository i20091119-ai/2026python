## 슬라이드 B — 파이썬에서 괄호란?

새로운 컨테이너를 만들 때 쓰이는 괄호

- `[대괄호]` : **리스트** 만들 때 대괄호 사용
- `{중괄호}` : **사전** 만들 때 중괄호 사용
- `(소괄호)` : **튜플** 만들 때 소괄호 사용

빨간 펜: 리스트 / 사전 / 튜플 각각 크게 동그라미, 괄호 모양과 연결선

> 괄호 모양만 보고 자료형을 맞히는 문제로 만들기 좋다.

## 슬라이드 C — 1.1 리스트

**리스트**
- 내용을 변경할 수 있음
- 함수로 항목을 쉽게 변경 가능

```python
my_list = ["one", "two", "three", "four"]
```

- 추가 : `append(x)`
- 정렬 : `sort( )`
- 뒤집기 : `revers( )`

빨간 펜: 대괄호 모양 `[` `]` 를 크게 그려 강조

> **슬라이드 오타**: 뒤집기가 `revers( )` 로 적혀 있는데 e 가 빠졌다.
> 실제 함수는 **`reverse()`** 다.
> 확인함: `revers()` 를 부르면 두 엔진 모두
> `AttributeError: 'list' object has no attribute 'revers'` 가 난다.
> 오히려 좋은 문제 소재 (오타로 나는 AttributeError).

## 화면 E — 0430.py · 슬라이스 대입, 빈 리스트, 중첩 리스트

```python
a = [ 1, 2, 3, 4, 5, "life", "love", "hate", 6, 7, 8 ]
b = [ 6, 7, 8, 9, 10 ]
b[0:2] = [100, 100]
c = []
d = [1, 2, [3, 4,5,6,7]]
print( b)
```

Shell (이전 실행 흔적 포함)
```
[6, 7, 8, 9, 10, 6, 7, 8, 9, 10, 6, 7, 8, 9, 10]     ← b * 3 을 해 본 흔적
>>> %Run 0430.py
[9, 7, 8, 9, 10]                                      ← b[0] = 9 를 해 본 흔적
>>> %Run 0430.py
```

세 가지 새로운 것
1. **슬라이스 대입** `b[0:2] = [100, 100]` → `[100, 100, 8, 9, 10]`
   (0번, 1번 두 자리를 통째로 바꾼다)
2. **빈 리스트** `c = []`
3. **중첩 리스트** `d = [1, 2, [3, 4, 5, 6, 7]]` → `d[2][1]` 은 `4`

> 확인함: 슬라이스 대입, 빈 리스트, 중첩 리스트, 그리고
> `append / sort / reverse`, 리스트 반복(`*`) 까지
> **CPython 과 브라우저 엔진 출력이 완전히 같다.** 그대로 문제로 써도 된다.
>
> | 코드 | 두 엔진 공통 출력 |
> |---|---|
> | `b[0:2] = [100, 100]; print(b)` | `[100, 100, 8, 9, 10]` |
> | `print(c)` | `[]` |
> | `print(d)` | `[1, 2, [3, 4, 5, 6, 7]]` |
> | `print(d[2][1])` | `4` |
> | `e=[3,1,2]; e.append(9)` | `[3, 1, 2, 9]` |
> | `e.sort()` | `[1, 2, 3, 9]` |
> | `e.reverse()` | `[9, 3, 2, 1]` |
> | `print(b * 2)` | `[100, 100, 8, 9, 10, 100, 100, 8, 9, 10]` |

## 적용 시 만들 예제 후보 (6주차 배치 1)

- 괄호 모양으로 자료형 맞히기 (객관식: 대괄호/중괄호/소괄호)
- 인덱스 표를 보고 `a[0]`, `a[5]`, `a[-1]` 맞히기
- 숫자와 문자열이 섞인 리스트에서 `a[0] + a[7]` 이 왜 오류인지, 고치는 방법 두 가지
  (`str(a[0]) + a[7]` 로 문자열 만들기 / 숫자끼리만 더하기)
- `revers()` 오타로 나는 AttributeError 고치기
- 슬라이스 대입으로 여러 자리를 한 번에 바꾸기
- 중첩 리스트에서 안쪽 값 꺼내기 `d[2][1]`
- `append` / `sort` / `reverse` 를 순서대로 적용한 결과 예측
