## 슬라이드 A — 2.4 반복문 · while 반복

- while 반복: 어떤 것이 참인 동안 실행되다가 거짓이 될 때 멈춤
- 예제
  - 같은 문장 50번 쓰기
  - while 문의 경우 숫자를 몇 번씩 세 가면서 반복 가능
  - 보기 좋은 코드와 복잡한 일 수행 가능한 자세한 코드 비교

CODE BOX 2.4
```python
lines = 0
while lines < 50:
    print("나는 수업 시간에 프로그래밍을 하지 않겠습니다.")
    lines = lines + 1
```

CODE BOX 2.5
```python
print("나는 수업 시간에 프로그래밍을 하지 않겠습니다.\n" * 50)
```

> 두 코드가 같은 결과를 내지만, 2.5 는 짧고 2.4 는 회차마다 다른 일을 시킬 수 있다는 대비가 핵심.

## 슬라이드 B — 2.4 반복문 · While 반복문의 동작

- 변수 : 메모리에 존재하며 문자열이나 정수 저장 가능

그림 속 코드와 주석
```python
number = 1
while number < 1:
    print(number)
    number = number + 1
```
- `number = 1` → 변수를 만들고 1이라는 값을 넣어줍니다
- `while number < 1:` → 콜론 다음으로 들여쓰기를 한 모든 코드를 실행합니다
- `print(number)` → 여기에는 인용 부호가 없는데 "number"라는 단어가 아니라
  변수 number 의 값을 찍으라는 뜻입니다
- `number = number + 1` → 변수 number 를 1씩 증가시킨다는 뜻입니다
- IDLE 에서 자동으로 들여쓰기가 됩니다

> **확인 필요**: 이 코드는 `number = 1` 인 상태에서 조건이 `number < 1` 이라
> 한 번도 실행되지 않는다(아무것도 출력 안 됨). 교재 그림의 오타로 보인다.
> 적용할 때 이 점을 짚어 주는 예제로 쓰면 좋겠다 (조건을 `< 10` 으로 바꿔 비교).

## 슬라이드 E — 3.1 스크립트 모드 · 간단한 코드 설명

- `#` 기호 : 주석, 컴퓨터가 아닌 사람을 위한 메모
- 모듈
  - 특별한 코드로 만들어진 파이썬 파일
  - **Import 뒤에 주로 쓰임**
  - 곳곳에서 불러 쓰기 좋은 편리함
- 문자열 변수 : 나중에 쓸 문자열을 저장한 변수

> **PDF 와 다른 점**: 내가 처음 읽은 PDF 에는 이 자리가 `Import random(1,6)` 이라고
> 잘못 적혀 있었다. 녹화본 슬라이드는 "Import 뒤에 주로 쓰임" 으로 고쳐져 있다.
> 적용할 때 녹화본 쪽을 따른다.

## 적용 시 만들 예제 후보

- while 반복 기본형: `lines = 0` 에서 시작해 조건이 거짓이 될 때까지 세기
- 문자열 반복(`* 50`)과 while 반복의 결과 비교 (같은 결과, 다른 쓰임)
- 조건을 잘못 써서 한 번도 안 도는 while (슬라이드 B 의 오타 활용)
- 주석 `#` 이 실행에 영향을 주지 않음을 확인하는 문제
- `import random` 으로 주사위 만들기 (모듈 개념)
- 대화형 모드 vs 스크립트 모드 차이를 묻는 객관식
