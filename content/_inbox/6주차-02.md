## 화면 G — insert() 를 인수 하나로 부르기

```python
a = [ 1, 7, 3, 6, 5, 3 ]

a.insert(0)

print( c )
```

Shell (이전 실행 흔적)
```
[3, 5, 6, 3, 7, 1]
>>> %Run 0430.py
[1, 7, 3, 6, 5, 3]
>>> %Run 0430.py
4
```

> **오류**: `insert()` 는 **위치와 값 두 개**가 필요하다. 하나만 주면
> `TypeError: insert() takes exactly 2 arguments (1 given)` (브라우저 엔진 기준).
> `a.insert(0, 100)` 처럼 써야 맨 앞에 100 이 들어간다.
> `append()` 는 인수가 하나인데 `insert()` 는 둘이라는 대비가 좋은 문제 소재.

## 슬라이드 I — 1.2 사전(딕셔너리)

- 항목을 가리키는 고유한 이름 가짐
- 인덱스로 **키 이름** 사용
- 키에는 문자열, 정수, 실수 또는 심지어 튜플도 사용 가능
- **콜론**으로 키와 키 값 구분

```python
my_dictionary = {1:"고양이", 2:"개", 3:"말", 4:"물고기"}
my_dictionary = {"1":"고양이", "2":"개", "3":"말", "4":"물고기"}
```

빨간 펜: 위에 `[ 0, 0, 0, 0 ]` 이라고 적어 리스트의 인덱스와 대비시키심.
`1 : "고양이"` 부분에 동그라미.

> **핵심 대비**: 리스트는 자리(0,1,2…)로 찾고, 사전은 **키**로 찾는다.
> 두 번째 예처럼 키가 `"1"`(문자열)이면 `my_dictionary[1]` 로는 못 꺼내고
> `my_dictionary["1"]` 이어야 한다. 아주 좋은 함정 문제.

## 화면 J — 사전에서 del 로 지우기

```python
a = { 1 : "one", "name" : "hong", 7 : "seven" }

del a[7]

print( a )
```

Shell
```
hong
>>> %Run 0430.py
{1: 'one', 'name': 'hong', 7: 'seven', 8: 'eight'}
>>> %Run 0430.py
{1: 'one', 'name': 'hong'}
```

> 한 사전 안에 **정수 키와 문자열 키가 섞여** 있어도 된다.
> `a[8] = "eight"` 로 새 항목을 추가했다가 `del a[7]` 로 지우는 과정이 보인다.

### 출력 순서 검증 (중요)

사전의 출력 순서가 엔진마다 다르면 채점이 깨진다. 실제로 확인했다.

| 코드 | CPython | 브라우저 엔진 |
|---|---|---|
| `print(a)` (8 추가 후) | `{1: 'one', 'name': 'hong', 7: 'seven', 8: 'eight'}` | 같음 |
| `del a[7]` 후 | `{1: 'one', 'name': 'hong', 8: 'eight'}` | 같음 |
| `{"name":"기사","hp":200,"mp":30,"level":5}` | 넣은 순서 그대로 | 같음 |
| `list(b.keys())` | `['name', 'hp', 'mp', 'level']` | 같음 |
| `for k in b:` 반복 순서 | 넣은 순서 | 같음 |

**두 엔진 모두 넣은 순서를 유지한다. 사전 문제를 내도 안전하다.**

## 슬라이드 K — 1.2 사전 함수 목록

- 키(key) list : `keys()`
- 값(Value) list : `values()`
- Key, value : `items()`
- 키로 value 얻기 : `get(key)`
- 해당 키가 있는지 조사하기 : `has_key` , `in`
- 모두 지우기 : `.clear()`

> **교재 내용 중 하나는 파이썬 3 에서 없어진 것이다.**
> `has_key()` 는 **파이썬 2 전용**이고 파이썬 3 에서는 삭제되었다.
> 확인함: 두 엔진 모두
> `AttributeError: 'dict' object has no attribute 'has_key'` 가 난다.
> 파이썬 3 에서는 **`in` 만** 쓴다.
> ```python
> if "name" in a:      # 이렇게
>     print(a["name"])
> ```
> 앱에 넣을 때 이 점을 반드시 짚어 줄 것. 시험에 나올 법한 함정이기도 하다.

## 슬라이드 L — 1.3 튜플

**튜플의 특징**
- 메모리에서 빠르게 동작
- 다른 코드로 항목을 삽입하거나 삭제 **불가**

```python
my_tuple = ("one", "two", "three", "four")
```

- 슬라이싱, 더하기, 곱하기, 길이 구하기는 **가능**
  - 슬라이싱 : `my_tuple[1:]`
  - 더하기 : `+` 사용
  - 곱하기 : `*` 사용
  - 길이구하기 : `len( my_tuple)`

빨간 펜: "삽입하거나 삭제 불가" 에 크게 동그라미와 X 표시, 각 항목에 밑줄

### 검증 결과

| 코드 | 두 엔진 공통 출력 |
|---|---|
| `print(t)` | `('one', 'two', 'three', 'four')` |
| `print(t[1:])` | `('two', 'three', 'four')` |
| `print(t + ("five",))` | `('one', 'two', 'three', 'four', 'five')` |
| `print(t * 2)` | 네 항목이 두 번 반복 |
| `print(len(t))` | `4` |
| `t[0] = "zero"` | TypeError (문구만 미세하게 다름) |

- CPython: `'tuple' object does not support item assignment`
- 브라우저 엔진: `'tuple' does not support item assignment`
- 오류 **종류**가 같으므로 채점에는 문제없다.
