## 슬라이드 P — ValueError 예외

- 변환할 수 없는 것을 변환하려 할 경우
- 숫자가 아닌 것을 숫자로 변환하려 할 경우

```python
int("안녕하세요")
float("안녕하세요")
```

오류
```
Traceback (most recent call last):
  File "intconvert.py", line 2, in <module>
    int_a = int(string_a)
ValueError: invalid literal for int() with base 10: '안녕하세요'
```

## 슬라이드 Q — 소수점 있는 문자열을 int() 로 바꿀 때

소수점이 있는 숫자 형식의 문자열을 `int()` 함수로 변환하려 할 때

```python
int("52.273")
```

오류
```
Traceback (most recent call last):
  File "intconvert.py", line 2, in <module>
    int_a = int(string_a)
ValueError: invalid literal for int() with base 10: '52.273'
```

> 이미 앱에 객관식으로 들어가 있는 내용. 유지하면 된다.

## 슬라이드 R — str() 함수

숫자를 문자열로 변환

```
str(다른 자료형)
```
슬라이드 위 별도 텍스트 상자: `"52.273"`

```python
output_a = str(52)
output_b = str(52.273)
print(type(output_a), output_a)
print(type(output_b), output_b)
```

실행결과
```
<class 'str'> 52
<class 'str'> 52.273
```

## 슬라이드 S — 키워드로 정리하는 핵심 포인트

- **변수 선언** : 변수를 생성하는 것을 의미
- **변수 할당** : 변수에 값을 넣는 것을 의미
- **변수 참조** : 변수에서 값을 꺼내는 것
- **input() 함수** : 명령 프롬프트에서 사용자로부터 데이터 입력 받음
- **int() 함수** : 문자열을 int 자료형으로 변환
- **float 함수** : 문자열을 float 자료형으로 변환
- **str() 함수** : 숫자를 문자열로 변환

슬라이드 오른쪽에 교수님이 직접 타이핑한 메모
```
b = 5
Print(b)
```

> **눈여겨볼 것**: `Print` 의 P 가 대문자다. 파이썬은 대소문자를 구분하므로
> `Print(b)` 는 `NameError: name 'Print' is not defined` 가 난다.
> 초보자가 가장 자주 겪는 오류라 문제로 만들기 좋다.
> (교수님이 판서하듯 빠르게 친 것으로 보이지만, 오히려 좋은 소재다.)

## 슬라이드 T — 정수형과 실수형 (「숫자」 단원 시작)

- **정수형**
  - 소수점이 없는 숫자
  - `0, 1, 273, -52`
  - **정수 (integer)**
- **실수형**
  - 소수점이 있는 숫자
  - `0.0, 52.273, -1.2`
  - **실수 (floating point, 부동 소수점)**

---

## 적용 시 만들 예제 후보 (배치 4)

- `Print(b)` 처럼 대소문자를 틀렸을 때 나는 NameError (객관식 또는 오류 고치기)
- `int("안녕하세요")` 와 `int("52.273")` 이 같은 ValueError 를 내는 이유
- `str(52)` 와 `52` 의 자료형 비교 (결과 예측)
- 숫자 → 문자열 → 다시 숫자로 왕복시키기
- 정수형과 실수형 구분: `52` 와 `52.0` 은 무엇이 다른가
