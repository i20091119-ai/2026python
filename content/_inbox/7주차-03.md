## 슬라이드 P — 키워드로 n 을 지정해서 문제 해결

```python
def print_n_times(*values, n=2):
    for i in range(n):
        for value in values:
            print(value)
        print()

print_n_times("안녕하세요", "즐거운", "파이썬 프로그래밍", n=3)
```
실행결과: 세 문장이 한 묶음으로 **3번** 반복

빨간 펜: `n=3` 을 크게 동그라미 치고 **"키워드"** 라고 적으심

> 앞 슬라이드에서 `3` 을 위치로 넘겼을 때 values 에 먹혀 버린 문제를
> `n=3` 으로 해결하는 장면. 이 단원의 핵심이다.
> 확인함: 두 엔진 모두 3번 반복.

## 슬라이드 Q — 기본 매개변수 중 필요한 값만 입력하기

```python
def test(a, b=10, c=100):
    print(a + b + c)

# 1) 기본 형태
test(10, 20, 30)
# 2) 키워드 매개변수로 모든 매개변수를 지정한 형태
test(a=10, b=100, c=200)
# 3) 키워드 매개변수로 모든 매개변수를 마구잡이로 지정한 형태
test(c=10, a=100, b=200)
# 4) 키워드 매개변수로 일부 매개변수만 지정한 형태
test(10, c=200)
```

실행결과 (확인함, 두 엔진 동일)
```
60
310
310
220
```

빨간 펜: `print(a + b + c)` 옆에 `return` 이라고 적으심 (다음 단원 예고)

> **읽는 법**
> - 1) `10 + 20 + 30 = 60`
> - 2) `10 + 100 + 200 = 310`
> - 3) 순서를 뒤섞어도 이름으로 찾아가므로 `100 + 200 + 10 = 310`
> - 4) `b` 를 생략했으므로 기본값 10 이 쓰여 `10 + 10 + 200 = 220`
>
> **3번과 4번이 이 슬라이드의 핵심.** 키워드를 쓰면 순서를 지킬 필요가 없고,
> 중간 것만 건너뛸 수도 있다. 아주 좋은 결과 예측 문제가 된다.

## 슬라이드 S — 자료 없이 리턴하기

- `return` 키워드 : 함수를 실행했던 위치로 돌아가게 함

```python
# 함수를 정의합니다.
def return_test():
    print("A 위치입니다.")
    return              # 리턴합니다.
    print("B 위치입니다.")

# 함수를 호출합니다.
return_test()
```

실행결과
```
A 위치입니다.
```

빨간 펜: `return` 에서 호출 위치로 되돌아가는 화살표를 크게 그리심

> **핵심**: `return` 을 만나면 함수가 **즉시 끝난다**. 그래서 B는 출력되지 않는다.
> 확인함: 두 엔진 모두 "A 위치입니다." 만 출력.

## 슬라이드 T — 자료와 함께 리턴하기

- 리턴 뒤에 자료 입력하면 자료 가지고 돌아감

```python
def return_test():
    return 100

value = return_test()
print(value)
```
실행결과: `100`

빨간 펜: `return 100` 의 100 에서 `value` 로 가는 화살표

> `print(no_return())` → `출력만` 다음 줄에 `None`. 두 엔진 동일.

## 슬라이드 V, X — 예시 · 범위 내부의 정수를 모두 더하는 함수

```python
# 함수를 선언합니다.
def sum_all(start, end):
    # 변수를 선언합니다.
    output = 0
    # 반복문을 돌려 숫자를 더합니다.
    for i in range(start, end + 1):
        output += i
    # 리턴합니다.
    return output

# 함수를 호출합니다.
print("0 to 100:", sum_all(0, 100))
print("0 to 1000:", sum_all(0, 1000))
print("50 to 100:", sum_all(50, 100))
print("500 to 1000:", sum_all(500, 1000))
```

실행결과 (확인함, 두 엔진 동일)
```
0 to 100: 5050
0 to 1000: 500500
50 to 100: 3825
500 to 1000: 375750
```

빨간 펜: `start`, `end` 에 동그라미와 `+ +` 표시

> 4주차의 "1부터 100까지 더하기" 를 **함수로 묶어 재사용**하는 형태.
> `end + 1` 을 쓰는 이유(끝 값 미포함)를 다시 짚을 수 있다.

## 슬라이드 Y — 기본 매개변수와 키워드 매개변수를 활용한 sum_all

```python
def sum_all(start=0, end=100, step=1):
    output = 0
    for i in range(start, end + 1, step):
        output += i
    return output

print("A.", sum_all(0, 100, 10))
print("B.", sum_all(end=100))
print("C.", sum_all(end=100, step=2))
```

실행결과 (확인함, 두 엔진 동일)
```
A. 550
B. 5050
C. 2550
```

빨간 펜: `start=0`, `end=100`, `step=1` 각각 동그라미

> **읽는 법**
> - A: `range(0, 101, 10)` → 0,10,…,100 의 합 = 550
> - B: 전부 기본값 → `range(0, 101, 1)` → 5050
> - C: step 만 2 → 0,2,…,100 의 합 = 2550
>
> 이 단원의 모든 개념(기본 매개변수 + 키워드 매개변수 + 리턴)이 한 예제에 모여 있다.
> **7주차 마무리 문제로 쓰기에 가장 좋은 코드.**

- `sum_all(start=0, end=100, step=1)` 로 확장하고 키워드로 호출하기
- 곱셈 누적 함수의 초깃값이 왜 1인지 (슬라이드 U 의 초깃값 이야기와 연결)
