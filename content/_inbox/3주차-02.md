## 슬라이드 F — 복합 대입 연산자

기본 연산자와 `=` 연산자 함께 사용해 구성

```python
a += 10
```

| 연산자 이름 | 설명 |
|---|---|
| `+=` | 숫자 덧셈 후 대입 |
| `-=` | 숫자 뺄셈 후 대입 |
| `*=` | 숫자 곱셈 후 대입 |
| `/=` | 숫자 나눗셈 후 대입 |
| `%=` | 숫자의 나머지를 구한 후 대입 |
| `**=` | 숫자 제곱 후 대입 |

## 슬라이드 G — 문자열의 복합 대입 연산자

문자열 역시 복합 대입 연산자 사용 가능

| 연산자 이름 | 설명 |
|---|---|
| `+=` | 문자열 연결 후 대입 |
| `*=` | 문자열 반복 후 대입 |

예시
```python
>>> string = "안녕하세요"
>>> string += "!"
>>> string += "!"
>>> print("string:", string)
string: 안녕하세요!!
```

그림 설명: 초깃값으로 "안녕하세요"를 넣으면
`안녕하세요` → `+ "!"` → `안녕하세요!` → `+ "!"` → `안녕하세요!!`
(상자 안에 변수 string 이 들어 있는 그림)

## 슬라이드 H — 사용자 입력 : input()

**input() 함수**
- 명령 프롬프트에서 사용자로부터 데이터 입력받을 때 사용

**input() 함수로 사용자 입력받기**
- **프롬프트 문자열** : input 함수 괄호 안에 입력한 내용
  ```python
  >>> input("인사말을 입력하세요> ")
  ```
- **블록 (block)** : 프로그램이 실행 중 잠시 멈추는 것
  ```
  인사말을 입력하세요> |
  ```
  주석: "입력 대기를 알려주는 커서입니다. 커서는 프로그램에 따라 모양이 다를 수 있습니다."
- 명령 프롬프트에서 글자 입력 후 [Enter] 클릭
  ```
  인사말을 입력하세요> 안녕하세요 [Enter]
  '안녕하세요'
  ```

> **주의 (적용 시)**: 마지막 줄의 결과가 따옴표가 붙은 `'안녕하세요'` 로 나온다.
> 이건 **대화형 모드**에서 리턴값을 그대로 보여줄 때의 모습이다.
> 우리 앱은 스크립트 모드로 실행하므로 `input(...)` 만 쓰면 아무것도 출력되지 않는다.
> 이 차이를 설명에 반드시 적어 줄 것. (다음 슬라이드 I 와 좋은 대비가 된다)

## 슬라이드 I — input 함수의 리턴값

input 함수의 결과로 산출 (리턴값)
- 다른 변수에 대입하여 사용 가능

```python
>>> string = input("인사말을 입력하세요> ")
인사말을 입력하세요> 안녕하세요 [Enter]
>>> print(string)
안녕하세요
```

> 슬라이드 H 는 따옴표가 붙은 `'안녕하세요'`, 여기 I 는 따옴표 없는 `안녕하세요`.
> H 는 값 자체를 보여준 것이고, I 는 `print()` 로 출력한 것이라 다르다.
> 이 대비가 좋은 문제 소재.

## 슬라이드 J — input() 함수의 입력 자료형

`type()` 함수로 자료형 알아봄

```python
>>> print(type(string))
<class 'str'>
```

```python
>>> number = input("숫자를 입력하세요> ")
숫자를 입력하세요> 12345 [Enter]
>>> print(number)
12345
```

```python
>>> print(type(number))
<class 'str'>
```

- **input() 함수는 사용자가 무엇을 입력해도 결과는 무조건 문자열 자료형**

## 적용 시 만들 예제 후보 (배치 2)

- `a = 2` 에서 `a += 3`, `a *= 4` 순서대로 적용했을 때의 값 (결과 예측)
- 문자열 `+=` 로 느낌표 붙여 나가기
- `"안녕" * 3` 과 `string *= 3` 의 차이
- `12345` 를 입력받아 `type()` 을 찍어 `<class 'str'>` 임을 확인
- 입력받은 값에 100 을 더하려다 TypeError 를 만나고 `int()` 로 고치기
- 대화형 모드의 `'안녕하세요'` 와 `print()` 의 `안녕하세요` 차이 (객관식)
