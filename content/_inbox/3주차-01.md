## 슬라이드 D — pi 로 숫자 연산하기

앞 예시에서 입력한 pi 는 숫자 자료에 이름 붙인 것이기 때문에 숫자 연산 모두 수행할 수 있음

```
>>> pi = 3.14159265
>>> pi + 2
5.14159265
>>> pi - 2
1.1415926500000002
>>> pi * 2
6.2831853
>>> pi / 2
1.570796325
>>> pi % 2
1.1415926500000002
>>> pi * pi
9.869604378534024
```

> **중요**: `pi - 2` 의 결과가 `1.1415926500000002` 로 나온다. 교재가 실수 오차를
> 그대로 보여 주고 있다. 지금 앱은 채점할 때 이 오차를 무시하도록 만들어 두었으니
> 이 슬라이드를 근거로 "왜 이런 값이 나오는지" 설명하는 자리를 만들면 좋겠다.
> 적용할 때 CPython 과 브라우저 엔진의 출력이 같은지 반드시 확인할 것.

## 슬라이드 E — 문자열과의 연산 불가 + 원의 둘레와 넓이

pi 는 숫자 자료이므로 숫자와 문자열 연산은 불가능
```python
pi + "문자열"
```

예시 — 원의 둘레와 넓이 구하기
```python
# 변수 선언과 할당
pi = 3.14159265
r = 10

# 변수 참조
print("원주율 =", pi)
print("반지름 =", r)
print("원의 둘레 =", 2*pi*r)    # 원의 둘레
print("원의 넓이 =", pi*r*r)    # 원의 넓이
```

실행결과
```
원주율 = 3.14159265
반지름 = 10
원의 둘레 = 62.831853
원의 넓이 = 314.159265
```

> **적용 메모**: 지금 앱의 「원의 넓이와 둘레」 문제는 반지름을 5 로 쓰고 있다.
> 교재가 10 을 쓰므로 10 으로 맞추는 게 좋다. 확인해 보니 `r = 10` 일 때
> CPython 과 브라우저 엔진의 출력이 `62.831853`, `314.159265` 로 똑같아서
> 그대로 써도 채점에 문제가 없다.

---

## 적용 시 만들 예제 후보

- 변수 선언 → 할당 → 참조 3단계를 순서대로 쓰는 문제
- 대화형 모드에서는 `변수` 만 쳐도 되지만 .py 파일에서는 `print(변수)` 가 필요한 이유
- `pi + "문자열"` 이 왜 TypeError 인지, 고치려면 어떻게 하는지
- 원의 둘레와 넓이 (교재 그대로 r = 10)
- `pi - 2` 의 끝자리가 이상한 이유 (실수 오차) — 결과 예측 문제로

## 두 엔진 실측 결과 (배치 1 기록 시점에 확인)

교재의 pi 연산을 CPython 과 브라우저 엔진(Skulpt)에서 각각 돌려 비교했다.

| 식 | CPython (교재와 동일) | 브라우저 엔진 |
|---|---|---|
| `pi + 2` | 5.14159265 | 5.14159265 |
| `pi - 2` | **1.1415926500000002** | **1.14159265** |
| `pi * 2` | 6.2831853 | 6.2831853 |
| `pi / 2` | 1.570796325 | 1.570796325 |
| `pi % 2` | **1.1415926500000002** | **1.14159265** |
| `pi * pi` | 9.869604378534024 | 9.869604378534024 |
| `2*pi*10` | 62.831853 | 62.831853 |
| `pi*10*10` | 314.159265 | 314.159265 |

결론
- 원의 둘레·넓이 예제는 **r = 10 그대로 써도 안전하다**. 두 엔진 출력이 같다.
- `pi - 2` 와 `pi % 2` 만 끝자리가 다르다. 채점 비교 함수가 이 차이를 흡수하는 것을
  확인했다 (`1.1415926500000002` 와 `1.14159265` 를 같다고 판정, 반면 `1.24159265`
  같은 진짜 다른 값은 정상적으로 다르다고 판정).
- 다만 **결과 예측 문제로는 쓰지 말 것**. 채점은 통과하더라도 화면에 보이는 정답과
  학생이 실행해서 보는 값이 달라 혼란스럽다. 설명용 예제로만 쓰고,
  "왜 끝자리가 이상한가" 를 짚어 주는 자리로 활용한다.
