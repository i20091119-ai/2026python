빨간 펜 판서: `1 ~ 10` 동그라미, `1 + + + + + 10`, `2 + ... + 2` 등

> **주의할 점**: 변수 이름으로 `sum` 을 쓰고 계신다. `sum` 은 파이썬 내장 함수 이름이라

> 실행은 되지만 좋은 습관은 아니라는 점을 짚어 주는 예제로 쓰면 좋다.

## 화면 6 — for 를 while 로 제대로 옮기고 나서 만난 SyntaxError

```python
sum = 0

s=int( input("처음 시작되는 값을 입력해 주세요") )
e=int( input("마지막 값을 입력해 주세요") )

#for i in range( s , e + 1 ) :
#    sum = sum + 1/i
#print(sum)
i=s
while i <= e :
    sum = sum + 1/i
    i = i + 1
print( sum )
```

Variables: `e = 10`, `i = 11`, `s = 1`, `sum = 2.9289682539682538`

Shell
```
2.9289682539682538
>>> %Run 92.py
Traceback (most recent call last):
  File "C:\Users\James\Desktop\프로그래밍\92.py", line 3
    s=int( input("처음 시작되는 값을 입력해 주세요") )    1
                                                        ^
SyntaxError: invalid syntax
```

빨간 펜 판서: `1 - 1/2 + 1/3 - 1/4 ... - 1/10` 형태로 항을 나열하고 마지막 `1/10` 에 동그라미

> **두 가지가 한 화면에 있다**
>
> 1. **for → while 변환 완성형**. `i = s` 로 시작값을 넣고, `while i <= e` 로 조건을 걸고,
>    `i = i + 1` 로 증가시킨다. `range(s, e+1)` 과 `while i <= e` 가 같은 범위라는 점이 잘 보인다.
>    직전 실행 결과 `2.9289682539682538` 은 1부터 10까지의 `1/i` 합이다.
>
> 2. **오타로 인한 SyntaxError**. 3행 끝에 실수로 `1` 이 하나 더 붙어 있다.
>    캐럿(`^`)이 그 위치를 가리킨다. 문법 오류는 **한 줄도 실행되기 전에** 나기 때문에,
>    앞줄이 멀쩡해도 프로그램 전체가 시작조차 못 한다는 것을 보여주는 좋은 예.
>    브라우저 엔진에서도 SyntaxError 로 잡히는 것을 확인했다(문구는 다름).

## 적용 시 만들 예제 후보 (4주차)

- 리스트 순회 `for a in [1,2,3,4,5]` 와 문자열 순회 `for a in "Hello"` 비교
- 반복이 끝난 뒤 변수에 남는 값 맞히기 (Variables 패널이 보여주던 것)
- `range(s, e+1)` 에서 `+1` 을 빼면 어떻게 되는지
- 같은 일을 for 와 while 두 가지로 작성하기 (교수님이 수업에서 하신 그대로)
- `sum` 을 변수 이름으로 쓰면 왜 곤란한지 (내장 함수 가림)
- 합이 50을 넘는 순간 찾기 (판서한 추적표를 해설에 표로 재현)
- 줄 끝 오타로 나는 SyntaxError: 앞줄이 멀쩡해도 전체가 실행 안 된다는 점
