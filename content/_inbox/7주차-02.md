## 슬라이드 H — TypeError · 매개변수를 더 많이 넣은 경우

```python
def print_n_times(value, n):          → 매개변수를 2개 지정했는데
    for i in range(n):
        print(value)

print_n_times("안녕하세요", 10, 20)    → 3개를 넣었습니다.
```

오류
```
TypeError: print_n_times() takes 2 positional arguments but 3 were given
```

> 두 오류 모두 브라우저 엔진에서도 TypeError 로 잡힌다. 다만 문구가 조금 다르다.
> | | CPython | 브라우저 엔진 |
> |---|---|---|
> | 부족 | `missing 1 required positional argument: 'n'` | `missing 1 required argument: n` |
> | 초과 | `takes 2 positional arguments but 3 were given` | `takes 2 positional arguments but 3 were  given` |
> 채점은 오류 종류로만 하므로 문제없다. 설명에 문구를 적을 때만 주의.

## 슬라이드 I — 가변 매개변수

- 매개변수를 원하는 만큼 받을 수 있는 함수

```
def 함수 이름(매개변수, 매개변수, ..., *가변 매개변수):
    문장
```

**제약**
- 가변 매개변수 뒤에는 일반 매개변수 올 수 없음
- 가변 매개변수는 하나만 사용할 수 있음

## 슬라이드 J — 예시 · 가변 매개변수 함수

```python
def print_n_times(n, *values):
    # n번 반복합니다.
    for i in range(n):
        # values는 리스트처럼 활용합니다.
        for value in values:
            print(value)
        # 단순한 줄바꿈
        print()

# 함수를 호출합니다.
print_n_times(3, "안녕하세요", "즐거운", "파이썬 프로그래밍")
```

실행결과: 세 문장이 한 묶음으로 3번 반복 (사이에 빈 줄)

> 확인함: 두 엔진 동일하게 동작.

## 슬라이드 K — 기본 매개변수

- 매개변수 값 입력하지 않았을 경우 매개변수에 들어가는 **기본값**

`print(value, ..., sep=' ', end='\n', file=sys.stdout, flush=False)`
← print 자체가 기본 매개변수를 쓰고 있다는 것을 다시 보여주심

```python
def print_n_times(value, n=2):
    for i in range(n):
        print(value)

print_n_times("안녕하세요")
```
실행결과
```
안녕하세요
안녕하세요
```

> 확인함: 두 엔진 동일.

## 슬라이드 L — 기본 매개변수가 가변 매개변수보다 **앞**에 올 때

**기본 매개변수의 의미가 사라짐**

```python
def print_n_times(n=2, *values):
    for i in range(n):
        for value in values:
            print(value)
        print()

print_n_times("안녕하세요", "즐거운", "파이썬 프로그래밍")
```

## 슬라이드 M — 그때 나는 오류

```
Traceback (most recent call last):
  File "test5_03.py", line 11, in <module>
    print_n_times("안녕하세요", "즐거운", "파이썬 프로그래밍")
  File "test.py", line 3, in print_n_times
    for i in range(n):
TypeError: 'str' object cannot be interpreted as an integer
```

> **왜 그런가**: 첫 번째 인수 `"안녕하세요"` 가 `n` 자리에 들어가 버린다.
> 기본값 `2` 는 무시되고, `range("안녕하세요")` 를 하려다 오류가 난다.
> 즉 **기본 매개변수를 앞에 두면 기본값을 쓸 방법이 없어진다.**
>
> 확인함: 두 엔진 **완전히 같은 메시지**
> `TypeError: 'str' object cannot be interpreted as an integer`

## 슬라이드 N, O — 가변 매개변수가 기본 매개변수보다 **앞**에 올 때

**가변 매개변수가 우선됨**

```python
def print_n_times(*values, n=2):
    for i in range(n):
        for value in values:
            print(value)
        print()

print_n_times("안녕하세요", "즐거운", "파이썬 프로그래밍", 3)
```

빨간 펜(슬라이드 O): `안~`, `즐~`, `파~` 를 세로로 적고 묶으심.
마지막 `3` 에도 밑줄 → **3 도 values 에 들어간다**는 것을 짚어 주심.

실행결과 (확인함, 두 엔진 동일)
```
안녕하세요
즐거운
파이썬 프로그래밍
3

안녕하세요
즐거운
파이썬 프로그래밍
3

```

> **핵심**: `3` 을 n 에 넣으려 했지만 가변 매개변수가 먼저 다 가져간다.
> `values` 는 `("안녕하세요", "즐거운", "파이썬 프로그래밍", 3)` 이 되고
> `n` 은 기본값 `2` 그대로라 **2번** 반복한다.
>
> 진짜로 n 을 3 으로 주려면 **키워드로 지정**해야 한다.
> ```python
> print_n_times("안녕하세요", "즐거운", n=3)
> ```
> 확인함: `b("가", "나", n=1)` 은 두 엔진 모두 한 번만 반복한다.
> 이것이 이 단원 제목이 "키워드 매개변수" 인 이유다.

## 적용 시 만들 예제 후보 (7주차 배치 2~3)

- 매개변수 개수를 틀렸을 때 나는 두 가지 TypeError 구분 (객관식)
- `print_n_times(value, n)` 직접 만들기
- 가변 매개변수로 "전달된 값을 모두 출력하는 함수" 만들기
- 기본 매개변수를 앞에 두면 왜 안 되는지 (결과 예측 → TypeError)
- **`*values` 뒤의 `n=2` 에 3을 위치로 넘기면 왜 무시되는지** (핵심 함정)
- 그것을 `n=3` 키워드로 고치기
- `print()` 의 `sep` / `end` 를 키워드로 바꿔 출력 형식 만들기
