# AI 프로그래밍 심화 워크북

2026학년도 2학기 「AI 프로그래밍 심화」(진주교육대학교 교육대학원 컴퓨터교육) 강의자료를
주차별 복습용 웹앱으로 만든 것입니다. 브라우저에서 바로 파이썬 코드를 작성하고 채점받을 수 있습니다.

## 무엇이 들어 있나

실제 강의 주차에 맞춰 2~7주차, 개념 40개, 문제 54개.

| 주차 | 내용 |
|---|---|
| 2 | 대화형/스크립트 모드, print(), 특수 문자열, 산술 연산자, while 맛보기, 주석, input()과 random |
| 3 | 변수, 복합 대입, input() 심화, 자료형 변환, 문자열과 인덱싱·슬라이싱, 숫자와 연산자 우선순위 |
| 4 | range(), for, while, break/continue, 누적 패턴 |
| 5 | 불 자료형, if/elif/else, 중첩 조건문, 논리 연산자 |
| 6 | 리스트, 사전(딕셔너리), 튜플 |
| 7 | 함수, 매개변수(가변·기본·키워드), 리턴 |

문제는 세 종류입니다.

- **코드 작성** — 직접 코드를 짜서 실행하면 출력을 정답과 비교해 채점합니다.
- **결과 예측** — 코드를 읽고 실행 결과를 맞힙니다.
- **객관식** — 오류가 나는 코드 고르기 등.

각 문제에는 단계별 힌트(접혀 있고 눌러야 보임)와 해설, 모범답안이 붙어 있습니다.

## 화면

수업에서 쓰는 **Thonny** 와 비슷한 배치로 만들었습니다.
줄 번호가 있는 편집기, `>>> %Run 파일명.py` 로 시작하는 Shell,
실행 후 변수에 무엇이 남았는지 보여주는 Variables 패널이 있습니다.
오류가 나면 Thonny 의 Assistant 처럼 한국어 도움말이 함께 나옵니다.

## 사용법

`dist/workbook.html` 파일 하나만 있으면 됩니다. 웹 서버나 인터넷 연결 없이
브라우저로 그냥 열면 동작합니다. (글꼴만 인터넷이 있으면 더 예쁘게 나옵니다.)

## 채점이 정확한 이유

화면에 보이는 모든 실행 결과와 정답은 손으로 적은 것이 아니라 **실제로 코드를 실행해서 만든 값**입니다.

- `tools/build.py` — 모든 예제와 모범답안을 진짜 CPython으로 실행해 `js/data.js`를 만듭니다.
  모범답안이 오류를 내거나 자체 채점을 통과하지 못하면 빌드가 실패합니다.
- `tools/verify_skulpt.js` — 브라우저 엔진(Skulpt)의 실행 결과가 CPython과 한 글자도 다르지 않은지
  145개 코드 전부에 대해 확인합니다. 두 엔진이 다르게 동작하면 맞는 답이 틀렸다고 나올 수 있기 때문입니다.

실수 계산의 끝자리 오차(`28.26` vs `28.259999999999998`)는 채점할 때 무시합니다.

## 직접 고치기

```bash
python3 tools/build.py           # 내용을 바꾼 뒤 데이터 다시 만들기
node tools/verify_skulpt.js      # 두 엔진 결과가 같은지 확인
python3 tools/build_artifact.py  # 단일 HTML 파일로 합치기
```

문제와 설명은 `content/week2.py` ~ `week7.py` 에 파이썬으로 적혀 있습니다.
강의를 들으며 모아 둔 원자료는 `content/_inbox/` 에 주차별로 남아 있습니다.
`blocks.py` 의 `P`, `CODE`, `TABLE`, `TIP`, `problem()` 같은 함수를 쓰면 새 문제를 쉽게 추가할 수 있습니다.

## 구성

```
content/     주차별 학습 내용과 문제 (사람이 고치는 곳)
runner/      파이썬 실행기 (CPython 쪽)
js/runner.js 파이썬 실행기 (브라우저 쪽, 같은 규칙)
js/app.js    화면 구성과 채점
tools/       빌드와 검증 도구
dist/        합쳐진 결과물
```
